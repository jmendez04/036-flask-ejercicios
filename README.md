Plataforma utilizada: Flask

## Contenido

Durante el desarrollo de los ejercicios se trabajaron los siguientes temas:

- Creación de una aplicación Flask
- Configuración de rutas
- Múltiples rutas
- Parámetros en la URL
- Métodos HTTP (GET y POST)
- Formularios HTML
- Plantillas con Jinja2
- render_template
- Archivos estáticos
- Uso de la carpeta static
- Formulario de contacto
- Organización de proyectos Flask
- Control de versiones con Git
- Repositorio en GitHub
